# Contributing to BIS Assistant

First off, thank you for considering contributing to the BIS Assistant! It's people like you that make open-source platforms better and more accessible.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue using the Bug Report template. Describe the issue in detail, including steps to reproduce, expected behavior, and actual behavior.

### Suggesting Enhancements
Have an idea for a new feature or improvement? We'd love to hear it! Open an issue using the Feature Request template and explain how your idea would benefit the platform.

### Pull Requests
1. Fork the repository and create your branch from main.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes (
pm run build).
5. Make sure your code lints.
6. Issue that pull request!
